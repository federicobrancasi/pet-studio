# Moves gallery

New moves taught to the VS Code pet. Each folder has the move as text (`move.txt`), previews
and `vscode/` sprite sheets in the exact format VS Code uses. To add yours, see the main
[README](../README.md#teach-the-pet-a-new-move).

| Move | What it does | Preview |
| --- | --- | --- |
| [`lgtm`](lgtm/move.txt) | Approves your pull request with a hop and a green check. | ![lgtm in Stable and Insiders colors](lgtm/preview.png) |
| [`wave`](wave/move.txt) | Waves hello with its right antenna. | ![wave in Stable and Insiders colors](wave/preview.png) |
